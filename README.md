# Inventario Galáctico 

Sistema en Java para registrar, comparar y ordenar el cargamento de una nave espacial utilizando programación genérica.

## Estructura de Misiones
* **Misión 1:** Clase genérica `Par<K, V>` (`Par.java`).
* **Misión 2:** Clase con tipos acotados `Caja<T extends Comparable<T>>` (`Caja.java`).
* **Misión 3:** Métodos estáticos genéricos en `Utilidades` (`Utilidades.java`).
* **Misión 4:** Integración y validación en `Main` (`main.java`).
